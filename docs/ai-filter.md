# AI 信息初筛

## 目标

对首页推荐卡片做批量打分/分类，把「值不值得看」的判断从逐张浏览变为一次初筛，
并按分数重排、打标。

## 工作方式

1. 设置页开启「AI 初筛卡片」，填写 OpenAI 兼容接口的 Base URL、API Key、模型名（如 `gpt-4o-mini`），可选填写偏好提示词。
2. 首页按 `Shift+Q`（或命令面板「AI 初筛当前页」）触发。
3. 内容脚本收集当前页卡片的公开元数据（标题、UP、时长、播放量、推荐原因），
   通过 `runtime.sendMessage` 交给 background。
4. background 请求 `{baseURL}/chat/completions`，要求模型返回严格 JSON：
   `{"results":[{"id","score":0-100,"category","reason"}]}`。
5. 内容脚本按 `score` 重排卡片（沿用筛选/排序的 `order` 机制），写入 `data-ai-score` /
   `data-ai-category` 属性，并提示「AI 初筛完成」。

## 隐私

- 默认关闭，需显式开启并配置服务。
- 只发送卡片标题、UP、时长、播放量、推荐原因等**公开信息**，不发送 cookie、账号信息、观看历史或视频内容。
- API Key 仅保存在扩展的 `storage.local`，请求由 background 发出，页面无法读取。

## 成本与降级

- 每页 30 张卡片合并为一次请求；评分结果按视频 URL 缓存 7 天（保存在扩展 `storage.local`），避免重复计费。
- 请求失败、超时或返回格式非法时静默降级：保持原顺序，不打断浏览。
- 如需进一步节省成本，可在提示词中要求模型只返回明显值得推荐的卡片。

## 选项

- **只保留推荐**：初筛后隐藏被判定为「广告 / 低质 / 重复」的卡片，仅保留「推荐」。
- **信息条展示分数**：高亮卡片的信息条会显示 `AI <分数> · <分类>`。

## 已知限制

- 依赖 OpenAI 兼容的 `/chat/completions` 与 `response_format: json_object`。
- 评分带模型主观性，仅作为排序参考，不替代个人判断。
- 首次请求前需自行确认所用服务可访问 B 站公开数据（无额外用途）。
