# 聚焦浏览（Cover Flow）

键盘模式下按内容流扫视时，网格布局会让视线在屏幕上来回游走。聚焦浏览把它变成**固定焦点的横向轨道**：

## 进入 / 退出

- 命令面板（`Ctrl/Cmd + K`）→「进入聚焦浏览（封面流）」
- `Esc` 退出，恢复原网格布局

## 交互

| 操作 | 行为 |
|---|---|
| 滚轮向上 / 向下 | 上一张 / 下一张 |
| `←` `↑` / `→` `↓` | 上一张 / 下一张 |
| `Esc` | 退出聚焦浏览 |
| `Enter` / `Space` | 仍在当前标签页 / 新标签页打开（复用键盘导航） |

## 视觉规则

- **主卡始终严格居中**：切换时卡片位置不变，只有相邻卡片横向流动（实测 12 次切换中心坐标恒定）
- 主卡宽约视口 42%（上限 880px），高度由内容决定（封面 + 标题 / UP / 播放量），不裁切信息
- 左右相邻卡片各露出约半张，带缩放、轻微旋转与压暗，形成方向提示
- 侧卡压暗由 `--bew-focus-dim` 控制，主卡描边为主题色
- 切换使用 320ms 缓动；首次进入禁用过渡，避免卡片从文档流位置"飞入"

## 实现要点

- 卡片不脱离原 DOM 顺序，只通过绝对定位 + transform 摆位，筛选/排序逻辑不受影响
- 舞台内非卡片分支（banner、直播、活动模块）会被隐藏，避免撑成巨大的区块
- Vue 重渲染会替换卡片节点，因此每次布局都重新收集卡片，并用视频 URL 记住当前 active
- wrapper 上同时挂 `bewly-focus-browse` 类，因为样式注入在 Shadow DOM 内、无法匹配外层 `html`
- 未完成摆位的卡片有 CSS 兜底（绝对定位 + 隐藏），避免以文档流尺寸显示
