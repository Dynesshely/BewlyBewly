# 聚焦浏览（Cover Flow）

键盘模式下按内容流扫视时，网格布局会让视线在屏幕上来回游走。聚焦浏览把它变成**固定焦点的横向轨道**：

## 进入 / 退出

- 命令面板（`Ctrl/Cmd + K`）→「进入聚焦浏览（封面流）」
- `Esc` 退出，恢复原网格布局

## 交互

| 操作 | 行为 |
|---|---|
| 滚轮向上 / 向下 | 上一张 / 下一张 |
| `←` `↑` / `→` `↓` | 上一张 / 下一张 |
| `Enter` | 在新标签页打开当前卡片 |
| `Space` | 在当前页打开内嵌预览抽屉（iframe 播放视频，不整页跳转；抽屉底部可「在新标签页打开」） |
| `Ctrl/Cmd + K` | 打开命令面板（与网格模式一致） |
| `Esc` | 退出聚焦浏览 |

## 视觉规则

- **主卡始终严格居中**：切换时卡片位置不变，只有相邻卡片横向流动（实测 12 次切换中心坐标恒定）
- **所有卡片宽度一致、等间距排成一条直线**：间距 = 卡片宽 + 18px，卡片之间不重叠，视觉上就是一整行
- **侧卡带 3D 翻转**：绕 Y 轴 ±20° 朝屏幕中心翻转，并后退 110px/级形成纵深（Cover Flow 观感）；
  主卡刻意保持纯 2D 变换 —— 它是唯一需要看清文字的卡片，落在 3D 合成上下文里会被重采样发虚
- 主卡宽约视口 41%（上限 840px），高度取所有卡片的最大自然高度并统一（偶数化，保证文字落在整数像素）
- 侧卡压暗由 `--bew-focus-dim` 控制，主卡描边为主题色
- 切换使用 380ms 缓动；首次进入禁用过渡，避免卡片从文档流位置"飞入"

## 卡片内信息区排版

- 信息区是一个两列网格：标题、UP 主占满整行；**播放量/弹幕在左列，发布时间等胶囊在右列同一行**
  —— 胶囊不再单独占一行贴在卡片底部，既不会溢出卡片，也提高了信息密度
- 封面与信息区之间留 18px；卡片四周内边距 16px；头像 34 → 39px

## 实现要点

- 卡片不脱离原 DOM 顺序，只通过绝对定位 + transform 摆位，筛选/排序逻辑不受影响
- 位置只由 `transform` 驱动，`left/top` 恒定为舞台中心：切换时没有未过渡的 `left/top` 跳变，因此不会抖动
- 舞台内非卡片分支（banner、直播、活动模块）会被隐藏，避免撑成巨大的区块
- Vue 重渲染会替换卡片节点，因此每次布局都重新收集卡片，并用视频 URL 记住当前 active
- wrapper 上同时挂 `bewly-focus-browse` 类，因为样式注入在 Shadow DOM 内、无法匹配外层 `html`
- 未完成摆位的卡片有 CSS 兜底（绝对定位 + 隐藏），避免以文档流尺寸显示
