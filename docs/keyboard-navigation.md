# 键盘卡片导航

实现：`src/composables/useKeyboardCardNavigation.ts`，在 `App.vue` 顶层安装（全局单例）。

## 交互语义

| 输入 | 行为 |
| --- | --- |
| 方向键 | 按网格移动高亮卡片（列数自动探测） |
| Home / End | 跳到第一张 / 最后一张 |
| Enter | 新标签页打开当前高亮视频 |
| Space | 当前标签页打开当前高亮视频 |
| 滚轮 | 默认逐张切换卡片（页面锁定滚动），每一下输入只切一张 |
| 1 - 6 | 切换首页标签页（个性推荐/关注/订阅剧集/热门/排行/直播） |
| / | 聚焦搜索框 |
| ? | 打开/关闭快捷键帮助面板 |
| d | 打开当前卡片的右键菜单（不感兴趣、稍后再看等） |
| Ctrl/Cmd + K | 打开命令面板（切 Tab / 排序 / 筛选 / 搜索 / 帮助 / 设置） |
| s | 循环切换卡片排序（默认 / 播放量 / 时长 / 最新） |
| f | 循环切换卡片筛选（全部 / 未看 / 长视频 / 已关注） |
| i | 切换底部信息条的精简 / 详细 |
| q | 把当前卡片加入本地待看队列（显示在信息条角标） |

## 高亮

- 通过 `data-keyboard-active` 属性标记（不用 class，避免 Vue 重渲染覆盖）。
- 切换后通过 OverlayScrollbars/原生滚动容器把卡片滚入视口（顶部留 96px、
  底部留 32px），并在下一帧断言可见性、失败时校正一次。

## 键盘模式总开关

- 命令面板（`Ctrl/Cmd + K`）提供「关闭 / 开启键盘卡片导航」命令，也可在设置页切换；
- **关闭后完全恢复原版交互**：方向键、滚轮、Enter/Space 都不再接管，高亮清除，鼠标点选与正常滚动生效；
- 命令面板本身始终可用（关闭状态下也能用它重新开启）。

## 设置项

`settings.keyboardNavLockScroll`（设置 → 首页）：

- 开启（默认）：滚轮锁定页面滚动、逐张切换卡片；
- 关闭：滚轮正常滚动页面，高亮跟随视口内卡片。

## 状态恢复

离开页面（`pagehide`）时把滚动位置与当前高亮视频 URL 写入 `sessionStorage`，
返回首页时恢复。

## 原生页面支持

- 搜索页等 B 站原生页面没有 Bewly 卡片标记，自动回退到 `.bili-video-card` 选择器；
- 打开视频时优先使用 `data-video-url`，否则从卡片内 `a[href*="/video/"]` 提取链接；
- 原生页面没有 Bewly 滚动容器实例，因此切换时不做滚动跟随（高亮与打开仍可用）。

## 已知限制

- 卡片通过 `[data-video-card]` / `.bili-video-card` 选择器识别，新页面若使用不同卡片结构需同步扩展。
- 点赞/收藏/稍后再看等写操作快捷键暂未提供（需要登录态写接口与 csrf 参数，风险较高）。
- 弹窗/输入框聚焦时自动放行按键（`hasOpenModal` / `isEditableTarget`）。
